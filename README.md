# Smarteye_dispenser
# 👁️ Eye Blink Controlled Eye Drop System 💧

## 📌 Overview
This project detects eye blinks using a webcam and triggers an action (simulated eye drop system).  
It is designed as a foundation for a **Raspberry Pi-based assistive healthcare device**.

---

## 🚀 Features
- 👁️ Real-time eye tracking using MediaPipe
- 👁️ Blink detection using Eye Aspect Ratio (EAR)
- 💧 Simulated eye drop trigger on blink
- ⏱️ Cooldown mechanism to avoid repeated triggers
- 🎥 Live webcam feed with visual feedback
- ⌨️ Press `q` to stop the camera

---

## 🛠️ Technologies Used
- Python 🐍
- OpenCV 🎥
- MediaPipe 🤖
- NumPy
